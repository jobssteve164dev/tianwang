# macOS 权限配置指南

## 概述

TianWang Agent 在 macOS 上需要特定的系统权限才能正常工作，特别是防火墙功能需要管理员权限。

## 必需的权限

### 1. 完全磁盘访问权限
**路径**: 系统偏好设置 > 安全性与隐私 > 隐私 > 完全磁盘访问权限

**用途**: 访问系统日志、网络配置等

**配置步骤**:
1. 打开系统偏好设置
2. 点击"安全性与隐私"
3. 选择"隐私"标签
4. 在左侧列表中选择"完全磁盘访问权限"
5. 点击锁图标解锁设置
6. 点击"+"按钮，添加 TianWang Agent 应用

### 2. 辅助功能权限
**路径**: 系统偏好设置 > 安全性与隐私 > 隐私 > 辅助功能

**用途**: 控制系统其他应用，发送系统通知

**配置步骤**:
1. 在"隐私"标签中选择"辅助功能"
2. 点击"+"按钮，添加 TianWang Agent 应用
3. 勾选应用以启用权限

### 3. 网络访问权限
**路径**: 系统偏好设置 > 安全性与隐私 > 防火墙

**用途**: 允许应用进行网络通信

**配置步骤**:
1. 在"安全性与隐私"中选择"防火墙"标签
2. 点击"防火墙选项"
3. 点击"+"按钮，添加 TianWang Agent 应用
4. 选择"允许传入连接"

## 防火墙功能权限

### 管理员权限要求
macOS 的防火墙功能 (pfctl) 需要管理员权限才能执行。应用会尝试以下方式获取权限：

1. **自动检测**: 检查是否有 sudo 权限
2. **用户提示**: 如果权限不足，会显示提示信息
3. **降级运行**: 权限不足时，防火墙功能会被禁用

### 手动启用防火墙
如果自动权限获取失败，可以手动启用：

```bash
# 启用 pf 防火墙
sudo pfctl -e

# 检查状态
sudo pfctl -s info

# 查看规则
sudo pfctl -s rules
```

## 故障排除

### 权限检查失败
如果应用报告权限不足：

1. 确认已授予所有必需权限
2. 重启应用
3. 检查系统日志中的错误信息

### 防火墙功能不可用
如果防火墙功能无法使用：

1. 确认 pfctl 命令可用: `which pfctl`
2. 确认有 sudo 权限: `sudo -n true`
3. 检查防火墙状态: `sudo pfctl -s info`

### 应用无法启动
如果应用无法启动：

1. 检查 Gatekeeper 设置
2. 确认应用已正确签名
3. 查看系统日志中的错误信息

## 安全注意事项

1. **最小权限原则**: 只授予应用必需的权限
2. **定期审查**: 定期检查应用的权限使用情况
3. **及时撤销**: 不再使用时及时撤销权限
4. **监控日志**: 关注应用的网络和系统访问日志

## 技术支持

如果遇到权限相关问题，请：
