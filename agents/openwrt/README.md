# OpenWrt 节点原型状态

本目录是早期 OpenWrt C 节点原型，不属于当前可发布、可构建或可验收的节点管线。

原型仍缺少日志、系统监控、安全执行、WebSocket 客户端等头文件与实现，也没有纳入当前 MCP 调查与响应任务信封、签名校验和精确回滚契约。根目录的统一构建与验证因此不会把本目录包装成受支持产物。

当前受支持节点实现位于 `agents/src`，覆盖 Linux、Windows 与 macOS，并作为 MCP 调查、证据回传、处置、验证和回滚闭环的唯一节点执行实现。若后续恢复 OpenWrt 支持，应先按同一外部契约补齐实现、交叉编译环境与实机验收，再重新接入统一构建。
