# TianWang Agent macOS 客户端安装指南

## 概述

TianWang Agent 是一个专为 macOS 设计的网络安全监控客户端应用。本文档将指导您完成安装、配置和使用过程。

## 系统要求

- **操作系统**: macOS 10.14 (Mojave) 或更高版本
- **架构**: Intel (x64) 或 Apple Silicon (ARM64)
- **内存**: 最少 4GB RAM，推荐 8GB 或更多
- **存储空间**: 至少 500MB 可用空间
- **网络**: 稳定的互联网连接

## 安装方法

### 方法一：DMG 安装包（推荐）

1. **下载安装包**
   - 从发布页面下载 `TianWang Agent-1.0.0.dmg` 文件
   - 文件大小约 93MB

2. **安装步骤**
   ```bash
   # 1. 双击 DMG 文件
   # 2. 将 TianWang Agent 拖拽到 Applications 文件夹
   # 3. 从 Applications 文件夹启动应用
   ```

3. **首次启动**
   - 系统可能会显示"无法验证开发者"的警告
   - 点击"仍要打开"或"打开"
   - 在系统偏好设置 > 安全性与隐私中允许运行

### 方法二：从源码构建

```bash
# 1. 克隆项目
git clone <repository-url>
cd tianwang/agents

# 2. 安装依赖
npm install

# 3. 构建应用
npm run dist:mac

# 4. 安装到 Applications
cp -r dist/mac/TianWang\ Agent.app /Applications/
```

## 首次配置

### 1. 启动应用

- 从 Applications 文件夹或 Spotlight 搜索启动
- 应用会在菜单栏显示托盘图标
- 主窗口会自动打开

### 2. 基本设置

1. **连接设置**
   - 点击"设置"按钮
   - 配置服务器地址和端口
   - 设置认证信息（如果需要）

2. **监控配置**
   - 选择要监控的系统资源
   - 设置监控间隔时间
   - 配置告警阈值

3. **安全设置**
   - 启用/禁用自动阻止功能
   - 配置防火墙规则
   - 设置白名单IP

### 3. 权限配置

macOS 可能需要以下权限：

```bash
# 网络访问权限
# 系统偏好设置 > 安全性与隐私 > 网络

# 完全磁盘访问权限（用于系统监控）
# 系统偏好设置 > 安全性与隐私 > 隐私 > 完全磁盘访问

# 辅助功能权限（用于系统控制）
# 系统偏好设置 > 安全性与隐私 > 隐私 > 辅助功能
```

## 使用指南

### 主界面功能

1. **状态监控**
   - 连接状态：显示与服务器的连接情况
   - 监控状态：显示系统监控的运行状态
   - 系统状态：显示 CPU、内存使用率
   - 安全状态：显示检测到的威胁数量

2. **控制按钮**
   - 开始监控：启动系统监控
   - 停止监控：停止系统监控
   - 设置：打开配置界面
   - 查看日志：显示详细日志
   - 网络诊断：运行网络连接测试

### 托盘菜单

右键点击菜单栏图标可以访问：

- **显示主窗口**：打开主界面
- **系统状态**：查看连接和监控状态
- **开始/停止监控**：控制监控服务
- **设置**：快速访问配置
- **关于**：查看版本信息
- **退出**：完全退出应用

### 设置界面

1. **监控设置**
   - 监控间隔：设置数据收集频率（10-300秒）
   - 开机自动启动：应用随系统启动
   - 最小化到托盘：关闭窗口时隐藏到托盘

2. **安全设置**
   - 自动阻止威胁IP：检测到威胁时自动阻止
   - 防火墙规则：配置自定义防火墙规则
   - 白名单管理：管理信任的IP地址

## 故障排除

### 常见问题

1. **应用无法启动**
   ```bash
   # 检查系统日志
   Console.app > 搜索 "TianWang Agent"
   
   # 重置应用
   rm -rf ~/Library/Application\ Support/tianwang-agent
   ```

2. **权限被拒绝**
   ```bash
   # 重新授予权限
   sudo chmod +x /Applications/TianWang\ Agent.app/Contents/MacOS/TianWang\ Agent
   ```

3. **网络连接失败**
   ```bash
   # 检查防火墙设置
   sudo pfctl -s rules
   
   # 检查网络连接
   ping <server-address>
   ```

4. **监控数据异常**
   ```bash
   # 查看详细日志
   tail -f ~/Library/Logs/TianWang\ Agent/main.log
   
   # 重启监控服务
   # 在应用中点击"停止监控"然后"开始监控"
   ```

### 性能优化

1. **减少资源占用**
   - 增加监控间隔时间
   - 禁用不必要的监控项目
   - 定期清理日志文件

2. **网络优化**
   - 使用有线网络连接
   - 配置代理服务器（如果需要）
   - 优化服务器地址设置

## 安全注意事项

### 1. 数据安全

- 所有监控数据都经过加密传输
- 本地存储的数据使用系统密钥加密
- 定期更新应用以获取安全补丁

### 2. 隐私保护

- 应用不会收集个人身份信息
- 监控数据仅用于安全分析
- 可以随时停止监控和删除数据

### 3. 系统安全

- 应用运行在受限环境中
- 使用 macOS 沙盒机制
- 遵循最小权限原则

## 更新和维护

### 自动更新

应用支持自动更新功能：

### 手动更新

```bash
# 4. 重新启动应用
```

### 数据备份

```bash
# 备份配置文件
cp -r ~/Library/Application\ Support/tianwang-agent ~/Desktop/backup/

# 备份日志文件
cp -r ~/Library/Logs/TianWang\ Agent ~/Desktop/logs-backup/
```
