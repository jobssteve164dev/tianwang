## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
采用了分层设计，创建了一个独立的、流式日志收集系统，完全独立于现有的logger系统。系统采用Node.js的child_process模块来启动和管理各个服务进程，通过流式传输收集所有console输出，并实现了自动滚动机制来管理日志文件大小。

### c. 关键代码片段
**日志收集器核心逻辑**
```javascript
// 启动AI引擎日志收集
startAIEngineLogger() {
    const aiProcess = spawn('python3', ['main.py'], {
        cwd: aiEngineDir,
        stdio: ['pipe', 'pipe', 'pipe'],
        env: { ...process.env, PYTHONUNBUFFERED: '1' }
    });
    
    // 收集stdout和stderr
    aiProcess.stdout.on('data', (data) => {
        const lines = data.toString().split('\n').filter(line => line.trim());
        lines.forEach(line => {
            this.writeLog('AI-ENGINE', line);
        });
    });
}
```

**日志滚动机制**
```javascript
writeLog(service, message) {
    const timestamp = new Date().toISOString();
    const logEntry = `[${timestamp}] [${service}] ${message}\n`;
    
    this.writeStream.write(logEntry);
    this.currentLines++;
    
    // 检查是否需要滚动日志
    if (this.currentLines > this.maxLines) {
        this.rolloverLog();
    }
}
```

## 6. 使用说明

### 快速开始
1. **启动开发环境（集成日志收集器）**:
   ```bash
   ./dev-start-with-logger.sh
   ```

2. **查看日志**:
   ```bash
   # 查看最后50行日志
   node scripts/dev-log-tail.js
   
   # 查看最后100行日志
   node scripts/dev-log-tail.js 100
   
   # 实时监控日志
   node scripts/dev-log-tail.js watch
   ```

3. **交互式日志查看器**:
   ```bash
   node scripts/dev-log-viewer.js
   ```

### 系统特性
- **流式收集**: 实时收集客户端、AI引擎、服务端的所有console日志
- **自动滚动**: 限制最大100000行，超出自动覆盖最开始的输出
- **独立运行**: 独立于已有的logger系统，不影响现有日志功能
- **自动管理**: 随系统启动和关闭，每次启动时清理并生成新文件
- **彩色输出**: 支持彩色日志显示，便于快速识别不同服务和错误级别

### 日志格式
```
[时间戳] [服务名] 日志内容
```

服务标识包括：
- `SYSTEM` - 系统级日志
- `CLIENT` - 客户端日志
- `SERVER` - 服务端日志
- `AI-ENGINE` - AI引擎日志
- `*-ERROR` - 各服务的错误日志
