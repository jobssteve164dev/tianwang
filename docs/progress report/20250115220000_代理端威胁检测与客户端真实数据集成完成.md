**2. 添加威胁告警发送逻辑（main.js）**
```javascript
securityService.on('threat', (threat) => {
    logger.warn('检测到安全威胁:', threat);
    if (mainWindow) {
        mainWindow.webContents.send('security-threat', threat);
    }
    
    // 发送威胁告警到服务器
    if (agentService) {
        agentService.sendThreatAlert(threat)
            .then(success => {
                if (success) {
                    logger.info('威胁告警已发送到服务器');
                } else {
                    logger.warn('威胁告警发送失败');
                }
            })
            .catch(error => {
                logger.error('发送威胁告警时出错:', error);
            });
    }
});
```

## 6. 技术架构总结

### 当前架构特点：

1. **混合分析模式**：
   - 代理端：实时威胁检测 + 快速响应
   - 服务器端：告警存储 + 集中管理
   - 客户端：告警展示 + 用户交互

2. **数据流向**：
   ```
   监控数据 → SecurityService分析 → 威胁检测 → 本地告警 + 服务器上报
   ```

3. **响应策略**：
   - 本地自动响应（防火墙阻止、进程终止）
   - 服务器集中管理（告警存储、状态更新）

### 架构优势：

1. **实时性**：本地分析确保毫秒级响应
2. **可靠性**：离线时仍可进行基础防护
3. **可扩展性**：为未来智能化扩展预留空间
4. **准确性**：结合本地和云端分析提高检测率
