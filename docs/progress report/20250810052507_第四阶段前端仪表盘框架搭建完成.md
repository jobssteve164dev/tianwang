### c. 关键代码片段

**主应用路由配置**
```typescript
// src/App.tsx
<Routes>
  <Route path="/login" element={
    isAuthenticated ? <Navigate to="/dashboard" replace /> : 
    <AuthLayout><LoginPage /></AuthLayout>
  } />
  <Route path="/*" element={
    isAuthenticated ? 
    <MainLayout>
      <Routes>
        <Route path="/dashboard" element={<DashboardPage />} />
        <Route path="/alerts" element={<AlertsPage />} />
        <Route path="/devices" element={<DevicesPage />} />
      </Routes>
    </MainLayout> : <Navigate to="/login" replace />
  } />
</Routes>
```

## 5. 自我评估与学习 (Self-Assessment & Learning)

*   **遇到的挑战**: 
    - Redux Toolkit的TypeScript类型配置较为复杂，需要创建自定义hooks来确保类型安全
    - Ant Design Pro组件的API与文档存在一些差异，需要实际测试来确定正确的属性配置
    - 项目初期的依赖安装和TypeScript编译器缓存问题需要特殊处理

*   **学到的教训**: 
    - 在大型React项目中，提前建立好类型安全的Redux hooks和store配置至关重要
    - 使用现代化的前端工具链时，需要仔细处理各种配置文件的兼容性问题
    - 采用分阶段开发策略，先建立框架再逐步完善功能，能够更好地控制项目复杂度
