**增强的窗口管理**:
```javascript
function showMainWindow() {
    console.log('showMainWindow被调用');
    logger.info('showMainWindow被调用');
    
    if (!mainWindow) {
        console.log('主窗口不存在，创建新窗口');
        logger.info('主窗口不存在，创建新窗口');
        createMainWindow();
        return;
    }

    try {
        if (mainWindow.isMinimized()) {
            mainWindow.restore();
        }
        
        if (!mainWindow.isVisible()) {
            mainWindow.show();
        }
        
        mainWindow.focus();
        
        // 确保窗口内容已加载
        if (mainWindow.webContents.isLoading()) {
            mainWindow.webContents.once('did-finish-load', () => {
                console.log('窗口内容加载完成');
                logger.info('窗口内容加载完成');
            });
        }
        
    } catch (error) {
        console.error('显示主窗口时出错:', error);
        logger.error('显示主窗口时出错:', error);
        mainWindow = null;
        createMainWindow();
    }
}
```

## 6. 技术细节 (Technical Details)

### 修复的核心问题总结

1. **托盘图标显示问题**:
   - **根本原因**: 复杂的菜单更新逻辑导致getContextMenu方法调用错误
   - **解决方案**: 简化托盘创建逻辑，移除复杂的动态菜单更新
   - **结果**: 托盘图标正常显示在macOS菜单栏中

2. **应用退出问题**:
   - **根本原因**: app.quit()在某些情况下被阻止
   - **解决方案**: 添加isQuitting标志和强制退出机制
   - **结果**: 用户可以通过菜单正常退出应用

3. **窗口显示问题**:
   - **根本原因**: 窗口重新打开时内容加载状态检查不完整
   - **解决方案**: 增强窗口管理逻辑，添加详细的状态检查
   - **结果**: 窗口重新打开时能够正确显示内容

### 技术改进点

- **错误处理**: 添加了完善的try-catch机制

## 7. 用户指南 (User Guide)

### 安装说明
1. 下载 `TianWang Agent-1.0.0.dmg` 文件
2. 双击打开DMG文件
3. 将应用拖拽到Applications文件夹
4. 从Applications文件夹启动应用

### 使用说明
1. **启动应用**: 从Applications文件夹启动，托盘图标会显示在菜单栏
2. **显示主窗口**: 双击托盘图标或右键选择"显示主窗口"
3. **打开设置**: 右键托盘图标选择"设置"
4. **退出应用**: 右键托盘图标选择"退出"

### 故障排除
- 如果托盘图标不显示，请确保应用安装在Applications文件夹中
- 如果窗口显示空白，请尝试重新启动应用
- 如果无法退出，请使用强制退出（Command+Option+Esc）
