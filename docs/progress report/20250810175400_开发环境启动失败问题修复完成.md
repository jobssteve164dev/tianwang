## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
通过深入分析启动失败的根本原因，发现AI引擎启动失败是因为Kafka服务未运行。项目使用Kafka 4.0版本，采用KRaft模式（不再需要Zookeeper），但启动脚本中缺少Kafka的安装和启动逻辑。采用了"根本原因分析 -> 问题定位 -> 解决方案实施"的方法论。

### b. 主要变更文件 (Key Changed Files)
*   `MODIFIED`: `dev-start.sh` - 添加Kafka服务启动逻辑，支持KRaft模式
*   `MODIFIED`: `server/ai-engine/src/main.py` - 恢复正确的Kafka服务启动逻辑

### c. 关键代码片段
**Kafka启动逻辑（KRaft模式）**
```bash
# 启动 Kafka 服务 (KRaft 模式，不需要 Zookeeper)
log_info "启动 Kafka 服务 (KRaft 模式)..."
kafka-server-start /usr/local/etc/kafka/server.properties &
KAFKA_PID=$!
echo $KAFKA_PID > .kafka.pid

# 等待 Kafka 启动
wait_for_service "localhost" "9092" "Kafka"
```
