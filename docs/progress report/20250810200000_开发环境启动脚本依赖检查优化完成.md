## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
采用了智能依赖检查机制，通过文件时间戳比较来判断依赖是否需要重新安装。主要优化包括：
1. **时间戳比较**: 使用 `package.json` 和 `node_modules` 的时间戳比较，只有当配置文件更新时才重新安装
2. **条件安装**: 只有在确实缺失或配置更新时才执行安装，避免不必要的重复操作
3. **强制安装选项**: 提供 `--force-install` 参数，允许用户强制重新安装所有依赖

### b. 主要变更文件 (Key Changed Files)
*   `MODIFIED`: `dev.sh` - 优化依赖检查和安装逻辑

### c. 关键代码片段
**智能依赖检查函数优化**:
```bash
# 检查根目录依赖
if [ ! -d "node_modules" ]; then
    missing_deps+=("根目录依赖")
    need_install=true
elif [ "package.json" -nt "node_modules" ]; then
    missing_deps+=("根目录依赖(package.json已更新)")
    need_install=true
fi
```

**条件安装逻辑**:
```bash
# 智能依赖检查和安装
if [ "$force_install" = true ]; then
    log_step "强制重新安装所有依赖..."
    install_dependencies
elif ! check_dependencies_installed; then
    log_step "检测到缺失依赖，开始安装..."
    install_dependencies
else
    log_step "所有依赖已就绪，跳过安装步骤"
fi
```

*   **正面影响**:
