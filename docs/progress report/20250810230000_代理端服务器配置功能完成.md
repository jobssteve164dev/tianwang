## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
为了解决代理端无法连接到开发环境服务器的问题，采用了以下设计思路：
1. **动态配置支持**: 将硬编码的服务器地址改为从持久化存储读取，支持用户动态修改
2. **配置界面**: 创建专门的设置界面，提供直观的服务器配置功能
3. **连接测试**: 提供连接测试功能，让用户能够验证配置是否正确
4. **自动重连**: 当配置变更时，自动重新连接服务器

### c. 关键代码片段
**AgentService配置管理**:
```javascript
// 从持久化存储加载配置
this.config = {
    serverUrl: this.store.get('serverUrl', 'ws://localhost:5555'),
    apiUrl: this.store.get('apiUrl', 'http://localhost:5555/api'),
    reconnectInterval: this.store.get('reconnectInterval', 5000),
    maxReconnectAttempts: this.store.get('maxReconnectAttempts', 10),
    heartbeatInterval: this.store.get('heartbeatInterval', 30000)
};

// 更新服务器配置
updateServerConfig(serverConfig) {
    // 验证和更新配置
    this.config.serverUrl = serverConfig.serverUrl;
    this.config.apiUrl = serverConfig.apiUrl;
    
    // 保存到持久化存储
    this.store.set('serverUrl', this.config.serverUrl);
    this.store.set('apiUrl', this.config.apiUrl);
    
    // 如果当前已连接，需要重新连接
    if (this.isConnected) {
        this.disconnect().then(() => {
            this.connect().catch(error => {
                logger.error('重新连接失败:', error);
            });
        });
    }
}
```

## 6. 使用说明

### 配置步骤
1. **打开设置界面**: 在代理端主界面点击"设置"按钮，或右键托盘图标选择"设置"
2. **配置服务器地址**: 
   - WebSocket服务器地址: `ws://localhost:5555`
   - API服务器地址: `http://localhost:5555/api`
3. **测试连接**: 点击"测试连接"按钮验证配置是否正确
4. **保存配置**: 点击"保存配置"按钮保存设置

### 默认配置
- **开发环境**: 
  - WebSocket: `ws://localhost:5555`
  - API: `http://localhost:5555/api`
- **生产环境**: 需要根据实际部署情况配置

### 故障排除
- 如果连接测试失败，请检查：
  1. 开发环境是否已启动
  2. 服务器端口是否正确（5555）
  3. 防火墙是否阻止了连接
  4. 网络连接是否正常

## 7. 技术细节

### 配置存储
- 使用 `electron-store` 进行配置持久化
- 配置文件位置: `~/Library/Application Support/tianwang-agent/config.json` (macOS)

### 配置项
- `serverUrl`: WebSocket服务器地址
- `apiUrl`: API服务器地址
- `reconnectInterval`: 重连间隔（毫秒）
- `maxReconnectAttempts`: 最大重连次数
- `heartbeatInterval`: 心跳间隔（毫秒）

### 自动重连机制
- 当配置变更时，如果当前已连接，会自动断开并重新连接
- 重连失败会记录错误日志，但不会影响应用正常运行
- 用户可以通过连接测试功能验证配置是否正确
