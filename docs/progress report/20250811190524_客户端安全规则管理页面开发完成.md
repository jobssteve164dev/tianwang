## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路

采用**前后端分离架构**，在现有AI引擎规则管理功能基础上，为客户端增加了一个完整的安全规则管理界面。后端通过Node.js服务器作为中间层，调用AI引擎的规则管理API；前端使用React + Ant Design构建现代化的用户界面，提供规则源管理、规则更新和统计信息展示功能。

**前端页面核心功能**
```typescript
// client/src/pages/security/SecurityRulesPage.tsx
const SecurityRulesPage: React.FC = () => {
  // 规则源管理状态
  const [ruleSources, setRuleSources] = useState<Record<string, RuleType>>({});
  const [statistics, setStatistics] = useState<RuleStatistics | null>(null);
  
  // 获取规则源列表
  const fetchRuleSources = async () => {
    const response = await securityRulesApi.getRuleSources();
    if (response.success) {
      setRuleSources(response.data);
    }
  };
  
  // 更新规则
  const updateRules = async (sourceType?: string, sourceName?: string) => {
    const response = await securityRulesApi.updateRules(
      sourceType && sourceName ? { source_type: sourceType, source_name: sourceName } : undefined
    );
  };
};
```
