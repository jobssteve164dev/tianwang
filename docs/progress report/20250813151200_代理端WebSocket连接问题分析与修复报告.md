## 2. 问题分析 (Problem Analysis)

### a. 问题现象
1. **代理端可以成功注册和认证** - 日志显示注册和认证API调用成功
2. **WebSocket连接失败** - 返回400错误，连接无法建立
3. **代理端显示离线状态** - 前端界面显示代理为离线状态

### b. 根本原因分析

#### 2.1 主要错误信息
从日志中识别出两个关键错误：
```
WebSocket连接密钥验证失败:
处理WebSocket连接失败: Cannot set properties of undefined (setting 'status')
```

#### 2.2 技术问题定位

**问题1: WebSocket连接密钥验证失败**
- **位置**: `server/src/services/WebSocketService.js` 第50-65行
- **原因**: 连接密钥验证逻辑存在问题
- **影响**: 导致WebSocket连接被拒绝

**问题2: 代理状态更新失败**
- **位置**: `server/src/services/WebSocketService.js` 第85-95行
- **原因**: `agent`对象可能为undefined时尝试设置属性
- **影响**: 服务器崩溃，连接处理失败

**问题3: 模型引用错误**
- **位置**: `server/src/services/WebSocketService.js` 多个方法中
- **原因**: 直接使用`Agent`而不是`models.Agent`
- **影响**: 数据库操作失败

## 3. 修复方案 (Fix Implementation)

### a. 修复内容

#### 3.1 WebSocket连接密钥验证优化
```javascript
// 修复前
if (connectionKey && decoded.connectionKey) {
  const keyValidation = keyManagementService.verifyConnectionKey({...});
  if (!keyValidation) {
    return false;
  }
}

// 修复后
if (connectionKey && decoded.connectionKey) {
  try {
    const keyValidation = keyManagementService.verifyConnectionKey({...});
    if (!keyValidation) {
      logger.warn('WebSocket连接密钥验证失败:', decoded.agentId);
      return false;
    }
  } catch (keyError) {
    logger.warn('WebSocket连接密钥验证失败:', keyError.message);
    return false;
  }
} else {
  logger.debug('WebSocket连接未提供连接密钥:', { 
    hasConnectionKey: !!connectionKey, 
    hasDecodedKey: !!decoded.connectionKey,
    agentId: decoded.agentId 
  });
}
```

#### 3.2 代理状态更新安全检查
```javascript
// 修复前
agent.status = 'online';
agent.lastSeen = new Date();
await agent.save();

// 修复后
if (agent) {
  agent.status = 'online';
  agent.lastSeen = new Date();
  await agent.save();
}
```

#### 3.3 模型引用修复
```javascript
// 修复前
await Agent.findOneAndUpdate(...)

// 修复后
await models.Agent.findOneAndUpdate(...)
```
