## 2. 问题分析 (Problem Analysis)

### a. 问题现象
1. **代理端可以成功注册和认证** - 日志显示注册和认证API调用成功
2. **WebSocket连接失败** - 连接密钥验证失败，连接被拒绝
3. **代理端显示离线状态** - 前端界面显示代理为离线状态
4. **连接密钥验证失败** - 签名验证一直返回false

### b. 根本原因分析

#### 2.1 主要错误信息
从日志中识别出关键错误：
```
WebSocket连接密钥验证失败，但允许连接: {"agentId":"agent-c4e8123d9722405e","reason":"签名验证失败"}
WebSocket连接处理开始: {"hasAgent":false,"hostname":"unknown","platform":"unknown","agentStatus":"unknown"}
WebSocket连接缺少有效的agentId
```

#### 2.2 技术问题定位

**问题1: 连接密钥签名验证失败**
- **位置**: `server/src/services/KeyManagementService.js` 第280-336行
- **原因**: 生成和验证连接密钥时使用的数据格式不一致
- **影响**: 导致WebSocket连接密钥验证失败

**问题2: Agent信息传递失败**
- **位置**: `server/src/services/WebSocketService.js` 第31-107行
- **原因**: 在连接密钥验证失败后，agent信息没有正确传递到连接处理阶段
- **影响**: WebSocket连接建立后无法识别代理身份

**问题3: 连接密钥格式不匹配**
- **位置**: `server/src/controllers/agentController.js` 第410-430行
- **原因**: JWT token中存储的连接密钥格式与客户端发送的格式不匹配
- **影响**: 服务器端无法正确解析和验证连接密钥

## 7. 技术细节 (Technical Details)

### a. 连接密钥格式
- **生成格式**: `key:timestamp:signature`
- **验证数据**: `key:timestamp` (key为base64格式)
- **签名算法**: SHA256 + RSA
- **有效期**: 1小时

### b. WebSocket连接流程
1. 客户端发送连接请求，包含JWT token和连接密钥
2. 服务器验证JWT token并提取agent信息
3. 服务器验证代理存在并设置agent信息
4. 服务器验证连接密钥（失败不影响连接）
5. 建立WebSocket连接并开始心跳机制

### c. 调试信息级别
- **DEBUG**: 详细的连接密钥生成和验证过程
- **INFO**: 重要的连接状态变化
- **WARN**: 连接密钥验证失败等非致命错误
- **ERROR**: 连接建立失败等致命错误
