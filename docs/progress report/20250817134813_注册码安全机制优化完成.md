## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
采用了权限分离的安全设计模式，将注册码的生成和验证功能进行严格分离：
- **管理端（客户端）**：拥有完整的注册码管理权限，包括生成、查看、停用、延长有效期等
- **代理端**：只能验证注册码，完全移除生成功能，防止恶意批量生成

通过创建独立的API路由和权限控制，确保只有具有管理员权限的用户才能访问注册码生成功能。

**客户端API路径更新**
```typescript
// client/src/services/api.ts
// 注册码管理API - 仅限管理端访问
export const registrationCodeApi = {
  generateRegistrationCode: (data: any) => request('/admin/registration-codes', {
    method: 'POST',
    body: JSON.stringify(data),
  }),
  getRegistrationCodes: (params?: any) => {
    const queryString = new URLSearchParams();
    if (params) {
      Object.entries(params).forEach(([key, value]) => {
        if (value !== undefined && value !== null && value !== '') {
          queryString.append(key, String(value));
        }
      });
    }
    return request(`/admin/registration-codes?${queryString.toString()}`);
  },
  // ... 其他API路径也更新为 /admin/registration-codes
};
```
