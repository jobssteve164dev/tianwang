# 天网安全监控系统 - 数据库启用指南

## 🚀 快速启用数据库

### 方法一：使用自动化脚本（推荐）

```bash
# 一键启用数据库
npm run db:enable
```

这个脚本会自动：
- 检查PostgreSQL服务状态
- 修改配置文件启用数据库连接
- 验证数据库连接
- 创建数据库（如果需要）
- 提供下一步操作指导

### 方法二：手动启用

#### 1. 修改配置文件
编辑 `dev.local` 文件：
```bash
# 将 SKIP_DB=true 改为 SKIP_DB=false
SKIP_DB=false

# 确保数据库名称正确
DB_NAME=tianwang
```

#### 2. 验证数据库连接
```bash
# 检查PostgreSQL服务
./scripts/dev-status.sh

# 测试数据库连接
psql -h localhost -p 5432 -U tianwang -d tianwang -c "\dt"
```

#### 3. 启动开发环境
```bash
npm run dev
```

## 🔧 常见问题解决

### PostgreSQL服务未启动
```bash
# macOS
brew services start postgresql

# Linux
sudo systemctl start postgresql
```

### 数据库连接失败
```bash
# 检查用户权限
psql -h localhost -p 5432 -U postgres -c "CREATE USER tianwang WITH PASSWORD 'tianwang123';"
psql -h localhost -p 5432 -U postgres -c "GRANT ALL PRIVILEGES ON DATABASE tianwang TO tianwang;"
```

### 端口被占用
```bash
# 清理环境
./scripts/dev-cleanup.sh
```

## 📊 数据库操作

### 查看数据库状态
```bash
# 查看表结构
psql -h localhost -p 5432 -U tianwang -d tianwang -c "\dt"

# 查看数据库大小
psql -h localhost -p 5432 -U tianwang -d tianwang -c "SELECT pg_size_pretty(pg_database_size('tianwang'));"
```

### 重置数据库
```bash
# 重置数据库（谨慎使用）
cd server && npm run db:reset
```

### 查看数据库日志
```bash
# 查看数据库相关日志
tail -f server/logs/dev.log | grep -i database
```

## 🎯 开发工作流

### 日常开发流程
1. **启动前检查**：`./scripts/dev-status.sh`
2. **启动服务**：`npm run dev`
3. **功能测试**：访问 http://localhost:3333
4. **停止服务**：`npm run dev:stop`

### 数据库开发流程
1. **启用数据库**：`npm run db:enable`
2. **启动服务**：`npm run dev`
3. **数据操作**：通过API或直接操作数据库
4. **验证功能**：测试数据持久化功能

## ⚠️ 注意事项

1. **数据安全**：开发环境的数据不会自动备份，重要数据请及时导出
2. **性能影响**：启用数据库会增加启动时间和资源消耗
3. **配置一致性**：确保 `dev.local` 中的数据库配置与实际环境一致
4. **服务依赖**：需要确保PostgreSQL服务持续运行
