# 本地AI模型管理界面用户手册

## 概述

本地AI模型管理界面是天网网络安全监控系统的重要组成部分，为系统管理员提供了直观、便捷的AI模型管理工具。通过该界面，管理员可以监控模型状态、训练模型、管理训练数据、查看性能指标和测试模型推理能力。

## 功能模块

### 1. 状态概览

**功能描述**: 查看所有本地AI模型的当前状态和性能指标。

**主要功能**:
- 显示模型训练状态（已训练/未训练/训练中）
- 展示模型准确率、精确率、召回率、F1分数等性能指标
- 显示推理时间和吞吐量
- 提供系统整体性能概览

**操作说明**:
1. 进入"本地AI模型管理"标签页
2. 默认显示"状态概览"页面
3. 点击"刷新状态"按钮更新最新数据
4. 查看各个模型的状态卡片和性能指标

### 2. 模型训练

**功能描述**: 手动触发模型训练，上传训练数据并监控训练进度。

**主要功能**:
- 选择要训练的模型类型
- 上传训练数据文件（JSON格式）
- 启动、暂停、停止训练任务
- 实时查看训练进度和指标

**操作说明**:
1. 点击"模型训练"标签页
2. 在"训练配置"区域选择目标模型
3. 上传训练数据文件或直接输入JSON数据
4. 点击"开始训练"按钮启动训练
5. 在"训练任务"区域查看训练进度
6. 可随时暂停或停止训练任务

**数据格式要求**:
- 文件格式：JSON
- 数据结构：数组格式，每个元素包含模型所需的特征字段
- 支持的数据类型：异常数据、正常数据、恶意软件数据、网络流量数据、用户行为数据

### 3. 数据管理

**功能描述**: 管理用于训练AI模型的数据集。

**主要功能**:
- 上传训练数据文件
- 查看数据列表和统计信息
- 删除不需要的数据
- 导出数据（开发中）

**操作说明**:
1. 点击"数据管理"标签页
2. 查看数据统计信息（总数据量、总样本数、已上传数量、平均样本数）
3. 点击"上传数据"按钮添加新数据
4. 在数据列表中查看、删除数据
5. 点击"刷新"按钮更新数据列表

### 4. 性能监控

**功能描述**: 监控和分析模型性能指标。

**主要功能**:
- 查看模型性能指标（准确率、精确率、召回率、F1分数、推理时间、吞吐量）
- 选择特定模型或查看所有模型
- 查看性能历史趋势（开发中）
- 获取性能优化建议

**操作说明**:
1. 点击"性能监控"标签页
2. 使用"选择模型"下拉菜单筛选特定模型
3. 查看性能指标卡片和系统概览
4. 阅读性能建议和优化提示
5. 点击"刷新数据"按钮更新性能数据

### 5. 测试工具

**功能描述**: 测试模型推理能力和准确性。

**主要功能**:
- 选择要测试的模型
- 上传测试数据或直接输入数据
- 查看推理结果和置信度
- 分析测试结果

**操作说明**:
1. 点击"测试工具"标签页
2. 选择要测试的模型类型
3. 上传测试数据文件或直接输入JSON数据
4. 点击"开始测试"按钮
5. 查看测试结果和性能指标

## 操作流程

### 新模型训练流程

1. **准备数据**
   - 收集符合模型要求的训练数据
   - 将数据整理为JSON格式
   - 确保数据质量和完整性

2. **上传数据**
   - 进入"数据管理"页面
   - 点击"上传数据"按钮
   - 选择模型类型和数据类型
   - 上传JSON数据文件

3. **开始训练**
   - 进入"模型训练"页面
   - 选择要训练的模型
   - 选择或上传训练数据
   - 点击"开始训练"按钮

4. **监控进度**
   - 在训练任务列表中查看进度
   - 监控准确率和损失值变化
   - 等待训练完成

5. **验证结果**
   - 进入"状态概览"查看训练后的模型状态
   - 使用"测试工具"验证模型性能
   - 查看"性能监控"中的详细指标

### 模型测试流程

1. **准备测试数据**
   - 准备符合模型输入格式的测试数据
   - 确保数据格式正确

2. **选择模型**
   - 进入"测试工具"页面
   - 选择要测试的模型类型

3. **上传数据**
   - 上传测试数据文件或直接输入数据
   - 确认数据格式正确

4. **执行测试**
   - 点击"开始测试"按钮
   - 等待推理完成

5. **分析结果**
   - 查看推理结果和置信度
   - 分析模型性能表现

## 常见问题

### Q1: 如何判断模型训练是否成功？

A: 可以通过以下方式判断：
- 查看"状态概览"中模型状态是否变为"已训练"
- 检查模型准确率是否达到预期水平
- 使用"测试工具"验证模型推理能力

### Q2: 训练数据格式有什么要求？

A: 训练数据需要满足以下要求：
- 文件格式：JSON
- 数据结构：数组格式
- 数据内容：包含模型所需的特征字段
- 数据质量：确保数据完整性和准确性

### Q3: 如何提高模型性能？

A: 可以通过以下方式提高模型性能：
- 增加训练数据量和质量
- 优化数据预处理流程
- 调整模型参数
- 使用更先进的算法

### Q4: 模型训练失败怎么办？

A: 如果模型训练失败，可以：
- 检查训练数据格式是否正确
- 确认数据量是否足够
- 查看错误日志信息
- 重新启动训练任务

### Q5: 如何备份和恢复模型？

A: 模型备份和恢复功能正在开发中，目前建议：
- 定期导出训练数据
- 记录模型配置参数
- 保存训练日志
