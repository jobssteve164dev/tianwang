# TianWang Agent 构建部署指南

## 概述

TianWang Agent 是一个基于 Electron 的桌面应用，用于网络安全监控。本文档提供了完整的构建和部署流程。

## 环境要求

- Node.js 20+
- npm 或 yarn
- macOS 10.14+ (用于构建 macOS 应用)
- Windows 10+ (用于构建 Windows 应用)
- Linux (用于构建 Linux 应用)

## 快速开始

### 1. 安装依赖

```bash
cd agents
npm install
```

### 2. 开发模式运行

```bash
npm start
# 或者
npm run electron-dev
```

### 3. 构建应用

```bash
# 构建前端资源
npm run build

# 构建可执行文件
npm run dist
```

## 详细构建流程

### 前端构建

```bash
npm run build
```

这个命令会：
- 将前端代码打包到 `build/` 目录
- 生成静态的 HTML、CSS 和 JavaScript 文件
- 优化资源大小

### 应用打包

```bash
# 构建所有平台
npm run dist

# 构建特定平台
npm run dist:mac    # macOS
npm run dist:win    # Windows  
npm run dist:linux  # Linux
```

### 构建配置

构建配置在 `package.json` 的 `build` 字段中定义：

```json
{
  "build": {
    "appId": "com.tianwang.agent",
    "productName": "TianWang Agent",
    "directories": {
      "output": "dist"
    },
    "files": [
      "src/**/*",
      "assets/**/*", 
      "build/**/*",
      "node_modules/**/*"
    ],
    "mac": {
      "category": "public.app-category.utilities",
      "target": "dmg"
    },
    "win": {
      "target": "nsis"
    },
    "linux": {
      "target": "AppImage",
      "category": "Utility"
    }
  }
}
```

## 部署选项

### 1. 开发环境

```bash
# 启动开发服务器
npm start
```

### 2. 生产环境

```bash
# 构建生产版本
npm run dist

# 运行生产版本
./dist/mac/TianWang Agent.app/Contents/MacOS/TianWang Agent
```

### 3. 自动更新

应用支持自动更新功能，通过以下方式配置：

```javascript
// 在 main.js 中配置
const { autoUpdater } = require('electron-updater');

autoUpdater.setFeedURL({
  provider: 'github',
  owner: 'your-username',
  repo: 'tianwang-agent'
});
```

## 故障排除

### 常见问题

1. **构建失败**
   ```bash
   # 清理缓存
   rm -rf node_modules
   npm install
   npm run build
   ```

2. **应用无法启动**
   ```bash
   # 检查日志
   tail -f ~/Library/Logs/TianWang Agent/main.log
   ```

3. **权限问题**
   ```bash
   # macOS 上可能需要授予权限
   sudo chmod +x dist/mac/TianWang\ Agent.app/Contents/MacOS/TianWang\ Agent
   ```

### 调试模式

```bash
# 启用调试日志
DEBUG=* npm start

# 打开开发者工具
# 在应用中按 Cmd+Option+I (macOS) 或 Ctrl+Shift+I (Windows/Linux)
```

## 性能优化

### 1. 构建优化

- 使用 `npm run build` 进行代码压缩
- 启用 Tree Shaking 移除未使用的代码
- 使用 CDN 加载外部资源

### 2. 运行时优化

- 启用硬件加速
- 使用 Web Workers 处理复杂计算
- 实现数据缓存机制

## 安全考虑

### 1. 代码签名

```bash
# macOS 代码签名
codesign --force --deep --sign "Developer ID Application: Your Name" dist/mac/TianWang\ Agent.app

# Windows 代码签名
signtool sign /f certificate.p12 /p password dist/win/TianWang\ Agent.exe
```

### 2. 安全配置

- 启用 CSP (Content Security Policy)
- 禁用 Node.js 集成
- 使用 contextIsolation
- 限制 IPC 通信

## 监控和日志

### 1. 日志配置

```javascript
// 在 logger.js 中配置
const winston = require('winston');

const logger = winston.createLogger({
  level: 'info',
  format: winston.format.combine(
    winston.format.timestamp(),
    winston.format.json()
  ),
  transports: [
    new winston.transports.File({ filename: 'error.log', level: 'error' }),
    new winston.transports.File({ filename: 'combined.log' })
  ]
});
```
