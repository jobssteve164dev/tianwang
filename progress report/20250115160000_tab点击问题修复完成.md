## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
问题分析发现，在Electron环境中，`event`对象可能没有正确传递到JavaScript函数中。采用了更可靠的DOM元素直接传递方式，通过传递`this`（按钮元素本身）而不是`event`对象来确保tab切换功能正常工作。

### b. 主要变更文件 (Key Changed Files)
*   `MODIFIED`: `agents/scripts/build.js` - 修改HTML onclick调用和JavaScript函数
*   `MODIFIED`: `agents/build/index.html` - 重新生成的HTML文件
*   `MODIFIED`: `agents/dist/TianWang Agent-1.0.0.dmg` - 重新构建的macOS应用

### c. 关键代码片段
**修改前的HTML调用**:
```html
<button class="tab-button active" onclick="switchTab('dashboard', event)">监控面板</button>
<button class="tab-button" onclick="switchTab('events', event)">事件列表</button>
<button class="tab-button" onclick="switchTab('logs', event)">系统日志</button>
```

**修改后的HTML调用**:
```html
<button class="tab-button active" onclick="switchTab('dashboard', this)">监控面板</button>
<button class="tab-button" onclick="switchTab('events', this)">事件列表</button>
<button class="tab-button" onclick="switchTab('logs', this)">系统日志</button>
```

**修改后的JavaScript函数**:
```javascript
// 切换标签页
function switchTab(tabName, buttonElement) {
    // 隐藏所有标签页内容
    document.querySelectorAll('.tab-content').forEach(tab => {
        tab.classList.remove('active');
    });
    
    // 移除所有标签页按钮的active状态
    document.querySelectorAll('.tab-button').forEach(btn => {
        btn.classList.remove('active');
    });
    
    // 显示选中的标签页
    document.getElementById(tabName + '-tab').classList.add('active');
    
    // 激活对应的按钮
    if (buttonElement) {
        buttonElement.classList.add('active');
    } else {
        // 如果没有buttonElement参数，通过tabName找到对应的按钮
        document.querySelectorAll('.tab-button').forEach(btn => {
            if (btn.textContent.trim() === getTabDisplayName(tabName)) {
                btn.classList.add('active');
            }
        });
    }
    
    // 如果切换到事件列表，加载事件数据
    if (tabName === 'events') {
        loadEvents();
        updateEventStats();
    }
    
    // 如果切换到系统日志，刷新日志数据
    if (tabName === 'logs') {
        refreshLogs();
    }
}
```
