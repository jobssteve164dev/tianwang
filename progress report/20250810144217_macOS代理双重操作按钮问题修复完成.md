## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
采用了完全自定义标题栏的方案，通过设置`frame: false`和`titleBarStyle: 'hidden'`来完全移除系统原生标题栏，避免与自定义控制按钮产生冲突。同时通过CSS的`margin-top: 28px`为自定义标题栏预留空间，确保界面布局正确。

### b. 主要变更文件 (Key Changed Files)
*   `MODIFIED`: `agents/src/main.js` - 移除原生标题栏配置，添加IPC处理器
*   `MODIFIED`: `agents/build/index.html` - 添加自定义标题栏样式和布局
*   `MODIFIED`: `agents/scripts/build.js` - 更新构建脚本中的HTML内容
*   `MODIFIED`: `client/src/index.css` - 修复CSS语法错误

### c. 关键代码片段

**主进程窗口配置**
```javascript
// agents/src/main.js
mainWindow = new BrowserWindow({
    // ...
    titleBarStyle: 'hidden',
    frame: false
});

// IPC处理器
ipcMain.handle('window-close', () => {
    mainWindow.close();
});
ipcMain.handle('window-minimize', () => {
    mainWindow.minimize();
});
ipcMain.handle('window-maximize', () => {
    if (mainWindow.isMaximized()) {
        mainWindow.unmaximize();
    } else {
        mainWindow.maximize();
    }
});
```

**自定义标题栏CSS**
```css
/* agents/build/index.html */
.titlebar {
    position: fixed;
    top: 0;
    left: 0;
    right: 0;
    height: 28px;
    background: #000000;
    -webkit-app-region: drag;
    z-index: 1000;
    display: flex;
    align-items: center;
    padding: 0 12px;
    border-bottom: 1px solid #333333;
}

.app-container {
    margin-top: 28px; /* 为标题栏预留空间 */
}
```
