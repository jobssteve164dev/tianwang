## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
采用了模块化的脚本设计，将开发环境的启动、停止、状态检查和清理功能分离为独立的脚本文件。使用 `dev.local` 文件作为开发环境变量管理的统一入口，确保环境配置的一致性和可维护性。脚本设计遵循了"一键启动、优雅停止、状态可视、问题诊断"的原则。

### c. 关键代码片段
**环境变量加载逻辑优化**
```javascript
// server/src/index.js
// 加载环境变量 - 优先加载 dev.local，然后加载 .env
const path = require('path');
const fs = require('fs');

// 检查是否存在 dev.local 文件
const devLocalPath = path.join(__dirname, '../../dev.local');
if (fs.existsSync(devLocalPath)) {
  require('dotenv').config({ path: devLocalPath });
  console.log('Loaded environment variables from dev.local');
} else {
  require('dotenv').config();
  console.log('Loaded environment variables from .env');
}
```

**启动脚本核心逻辑**
```bash
# scripts/dev-start.sh
# 检查环境变量文件
check_env_file() {
    if [ ! -f "dev.local" ]; then
        log_error "dev.local 文件不存在"
        exit 1
    fi
}

# 启动服务端
start_server() {
    # 设置环境变量
    export $(cat ../dev.local | xargs)
    
    # 启动服务
    npm run dev &
    SERVER_PID=$!
    echo $SERVER_PID > .server.pid
}
```

## 6. 功能特性总结

### 核心功能
- **一键启动**: `npm run dev` 启动完整的开发环境
- **优雅停止**: `npm run dev:stop` 停止所有服务并清理资源
- **状态监控**: `npm run dev:status` 实时查看服务状态和端口占用
- **环境清理**: `npm run dev:cleanup` 清理端口冲突和残留进程
- **环境测试**: `npm run dev:test` 验证开发环境是否正常工作

### 技术特性
- **环境变量管理**: 使用 `dev.local` 文件统一管理开发环境配置
- **智能端口检查**: 自动检测端口占用，避免冲突
- **进程管理**: 使用PID文件跟踪进程，支持优雅停止
- **错误处理**: 完善的错误处理和用户友好的提示信息
- **跨平台兼容**: 支持 macOS、Linux 等操作系统

### 用户体验
- **彩色输出**: 使用颜色区分不同类型的信息
- **详细日志**: 提供详细的执行过程和状态信息
- **快速诊断**: 内置问题诊断和解决建议
- **完整文档**: 提供快速指南和详细文档
