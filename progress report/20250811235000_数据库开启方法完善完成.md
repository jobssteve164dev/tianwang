## 6. 故障排除指南

### 常见问题及解决方案

#### 1. 数据库连接失败
```bash
# 错误：FATAL: database "tianwang" does not exist
# 解决方案：
cd server && npm run db:init
```

#### 2. 用户认证失败
```bash
# 错误：FATAL: password authentication failed
# 解决方案：
# 检查 dev.local 中的 DB_USER 和 DB_PASSWORD 配置
# 确保PostgreSQL用户存在且有正确权限
```

#### 3. 端口被占用
```bash
# 错误：EADDRINUSE
# 解决方案：
./scripts/dev-cleanup.sh
# 或手动停止占用端口的进程
```

#### 4. 表结构同步失败
```bash
# 错误：Sequelize sync failed
# 解决方案：
# 检查数据库权限
# 确保数据库用户有创建表的权限
psql -h localhost -p 5432 -U tianwang -d tianwang -c "GRANT ALL PRIVILEGES ON DATABASE tianwang TO tianwang;"
```
