## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
采用了"真实数据优先，优雅降级"的设计思路。所有威胁检测规则和威胁情报都使用真实数据源，不再依赖任何模拟数据。实现了多层回退机制：优先使用本地规则文件，其次尝试从外部仓库下载，最后创建基础默认规则。对于威胁情报，支持MISP和OTX双源配置，确保即使某个源不可用，系统仍能正常运行。

**YARA规则优雅降级机制**
```python
# server/ai-engine/src/rules/yara_manager.py
async def load_rules(self) -> int:
    """加载YARA规则"""
    try:
        # 1. 首先尝试加载本地规则
        local_count = await self._load_local_rules()
        
        # 2. 如果本地规则数量不足，尝试下载外部规则
        if local_count < 50:
            await self._download_external_rules()
            local_count = await self._load_local_rules()
        
        # 3. 如果仍然没有规则，创建默认规则
        if local_count == 0:
            await self._create_default_rules()
            local_count = await self._load_local_rules()
        
        return local_count
    except Exception as e:
        logger.error(f"加载YARA规则失败: {e}")
        return 0
```
