## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
采用了模块化设计和真实数据驱动的开发方法：
1. **真实数据原则**: 所有图表数据都从威胁告警列表中统计获取，严禁使用模拟数据
2. **响应式布局**: 根据屏幕尺寸动态调整图表高度和布局，确保所有图表都能在一个页面内显示
3. **组件化设计**: 创建独立的图表组件，便于维护和复用
4. **数据分类统计**: 按照威胁类型、IP地址、攻击类型等维度进行数据聚合和可视化

```javascript
// server/src/routes/dashboard.js
router.get('/threat-ips', async (req, res) => {
  // 统计威胁IP
  const threatIPStats = await models.Alert.findAll({
    attributes: [
      'sourceIP',
      'severity',
      [models.sequelize.fn('COUNT', models.sequelize.col('id')), 'count'],
      [models.sequelize.fn('MAX', models.sequelize.col('timestamp')), 'lastSeen']
    ],
    where: {
      sourceIP: {
        [Op.not]: null,
        [Op.ne]: ''
      }
    },
    group: ['sourceIP', 'severity'],
    order: [[models.sequelize.fn('COUNT', models.sequelize.col('id')), 'DESC']],
    limit: 20,
    raw: true
  });
});
```
